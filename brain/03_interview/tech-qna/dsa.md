# Data Structures & Algorithms Q&A

### Q1: What is Time & Space Complexity of QuickSort and MergeSort?
- **QuickSort:** Average Time O(N log N), Worst Time O(N^2), Space O(log N).
- **MergeSort:** Time O(N log N) all cases, Space O(N).

### Q2: When to use BFS vs DFS?
- **BFS (Queue):** Finding shortest path in unweighted graphs or level-order traversal.
- **DFS (Stack/Recursion):** Exploring all paths, detecting cycles, topological sorting, connected components.
