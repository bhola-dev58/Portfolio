# SQL Q&A

### Q1: Difference between INNER JOIN, LEFT JOIN, and RIGHT JOIN?
- `INNER JOIN`: Returns records matching in both tables.
- `LEFT JOIN`: Returns all records from left table and matched records from right table.
- `RIGHT JOIN`: Returns all records from right table and matched records from left table.

### Q2: What are ACID properties in relational databases?
Atomicity (all or nothing), Consistency (valid state transitions), Isolation (concurrent transactions don't interfere), Durability (committed data persists).
