# Project Overview

## What is this site?
Personal software engineering portfolio website of Bhola Yadav.
It displays profile information, technical skills, engineering projects/case studies, internship experience, certifications, education, and provides a contact form and an Admin CMS for content management.

## Key Goals
- Showcase full-stack engineering and AI/ML capability to recruiters and clients.
- Provide dynamic, database-driven CMS ("My Work") for adding and updating projects without redeploying code.
- Serve as the foundation for an interactive AI agent assistant (Phase 4).

## Domain & Live URLs
- **Live Site:** `https://bhola-yadav.vercel.app/` (or `https://bhola-yadav.com.np`)
- **Backend API:** Express server running on port 5000 (deployed on cloud host / VPS / Docker).
